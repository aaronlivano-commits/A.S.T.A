in order to run up the system here is the step for each frontend and backend command

backend:
1. cd backend
2. install all the dependency: pip install -r requirements.txt (if starting fresh)
3. run the server: uvicorn app.main:app --reload
4. in order to stop the server just press ctrl+c on the Terminal

frontend:
1. cd frontend
2. install all the dependency: npm install (if starting fresh)
3. run the server: npm run dev
4. Follow the instructions to start the website and open the provided link
    Shortcuts is below: 

    press r + enter to restart the server
    press u + enter to show server url
    press o + enter to open in browser
    press c + enter to clear console
    press q + enter to quit

This should run the entire system up and running!
